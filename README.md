# Markdown-View-on-Vs-Code

The best way to view a `.md` (Markdown) file clearly in Visual Studio Code is to use the built-in Markdown Preview. It displays the document with proper formatting instead of showing raw Markdown syntax.

## 1. Open Markdown Preview (recommended)

1. Open your `.md` file in VS Code.
2. Press:

   `Ctrl + Shift + V`
3. VS Code opens a formatted preview of your Markdown document.

For example, instead of seeing:

```
# GraphQL Security Assessment

## Findings

- Alias Overloading
- Directive Overloading

**Severity:** High
```

You'll see a properly formatted document with headings, bullet points and bold text.

## 2. View Markdown side by side

This is particularly useful when editing README files.

Press:

`Ctrl + K`, then `V`

This opens the Markdown preview alongside your editor.

## 3. Open preview in a separate tab

You can also:

1. Right-click inside your `.md` file.
2. Select Open Preview.

Or click the preview icon in the top-right corner of the editor.

## 4. Useful Markdown extensions

If you want a better Markdown experience, consider:

- Markdown All in One – shortcuts, automatic table of contents, formatting and more.
- Markdown Preview Enhanced – advanced previews, diagrams, mathematical expressions and export options.

You can install them from `Ctrl + Shift + X`.

My recommendation

For your security assessment documentation and GitHub README files, use Markdown Preview to the Side (`Ctrl + K`, `V`).

You can edit your Markdown on the left and see exactly how the documentation will look when rendered on GitHub on the right.
